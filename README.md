# Feng Shui

![license](https://img.shields.io/badge/license-MIT-green) [![GitHub](https://img.shields.io/badge/GitHub-nulljosh%2Ffengshui-black?logo=github)](https://github.com/nulljosh/fengshui)

A pocket guide to fengshui principles, condensed from *Good Fengshui* by Eva Wong. Web + native iOS.

## Files

- `index.html` — chapter reader with sidebar TOC (same viewer pattern as [uprighty](https://github.com/nulljosh/uprighty))
- `content.md` — chapter source, shared by web and iOS

## iOS App

`ios/FengShui` is a native SwiftUI app: a chapter list that renders `content.md` inline, no backend.
